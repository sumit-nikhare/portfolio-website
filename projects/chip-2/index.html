01 / THE SHORT VERSION

Useful work.
A clear contribution.

Mobile and web platform UX for public-health teams, bringing consistent navigation, shared patterns, and role-aware workflows across programme modules.

I led end-to-end UX for multi-module healthcare workflows, translating field operations into navigation, role-visible actions, forms, approvals, and implementation specifications.

This case summary is based on my résumé. The diagrams were recreated for this portfolio to explain the workflow; they are not production screenshots or archived research artifacts.

02 / THE CHALLENGE

Make the work
easier to understand.

Frontline workers, supervisors, facility teams, and administrators need different actions within the same platform. High-volume entry, assisted usage, and unreliable connectivity make inconsistent patterns especially costly.

03 / DESIGN DECISIONS

Structure before
surface detail.

01

Make roles visible

Use role-aware navigation and permission-driven actions so the interface reflects what each person can do.

02

Reuse the useful patterns

Standardize forms, search, queues, status states, and approval flows across modules.

03

Design for field conditions

Account for assisted use, low-end devices, validation, and low-connectivity states in the interaction model.
