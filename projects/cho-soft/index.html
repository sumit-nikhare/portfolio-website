Mobile and dashboard experiences for facility workflows, with task queues, supervisor review, and exception handling.

I designed CHO Soft mobile and dashboard experiences, introducing task queues, supervisor review patterns, and exception or error states for facility workflows.

This case summary is based on my résumé. The diagrams were recreated for this portfolio to explain the workflow; they are not production screenshots or archived research artifacts.

02 / THE CHALLENGE

Make the work
easier to understand.

A task can move between a facility user and a supervisor before it is complete. The interface needs to make ownership, progress, and the next action clear at each handoff.

03 / DESIGN DECISIONS

Structure before
surface detail.

01

Show the next action

Use task queues to organize the work that needs attention.

02

Make review explicit

Separate preparation, submission, and supervisor review so each role has a clear responsibility.

03

Explain exceptions

Treat errors and returned work as supported states with a useful path forward.
