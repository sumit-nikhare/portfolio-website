Motion should explain

A transition earns its place when the interface remains understandable with it switched off.

Name the change before the animation

Start by writing a sentence about the interface: a panel opens, a selected item moves, or a set of results changes. That sentence is the reason for the transition. An easing curve is a later decision.

In this portfolio, the project collection can change between a grid and a list. Keeping the same project imagery and titles across those layouts gives the change a recognizable anchor. The layout animation is an enhancement to that relationship.

Use continuity carefully

A cover that expands into a case-study image can suggest that the next page belongs to the selected project. That relationship is useful only when navigation remains reliable. A missed transition must still arrive at the intended page.

This site uses ordinary links and native page navigation. Supported browsers may animate the change; the destination does not depend on that animation. The title, opening summary, and image provide the context after arrival.

Make the visitor’s choice real

W3C’s guidance for animation triggered by interaction describes giving people a way to disable nonessential movement. This is particularly relevant to scrolling effects and parallax. Read the W3C explanation.

The portfolio starts from the system motion preference and remembers an explicit choice. Reduced motion removes the pinned sculpture, distortion, and parallax. The case studies, controls, and artwork remain available.

Know when the movement is over

A hover effect can become background noise if it continues after the pointer has stopped. The project-cover distortion here fades back to the original image once movement settles. It is meant as a brief response, not a permanent visual layer.

Animation also needs a lifecycle. Graphics should stop requesting frames when their scene is outside the viewport or the browser tab is hidden. These implementation choices support a quieter experience as well as a lighter page.

Review the still version

Turn off motion and complete the same tasks: navigate to a project, open an image, change a filter, and return to the collection. Look for explanations that were carried only by movement.

Then turn motion back on and ask what each effect adds. If the answer is unclear, simplify it. This review is a design exercise rather than a substitute for testing with people who have different access needs.
